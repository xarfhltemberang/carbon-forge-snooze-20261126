# Snooze Button Roast

A one-line roast of an alarm clock that rings at 6 AM on a Saturday: the clock as a tiny landlord collecting rent for a day you don't even live in. Fresh angle, concrete image, punchline lands in the last few words.

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (single line, no trailing newline).
